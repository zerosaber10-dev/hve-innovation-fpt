# ADR Compact Summary

* **ADR ID:** ADR-0001
* **Title:** Choose the agentic HR architecture
* **Status:** proposed
* **ADR Path:** docs/planning/adrs/0001-choose-agentic-hr-architecture.md
* **Date:** 2026-09-28

## Key Decision

The proposed baseline uses LangGraph orchestration and MCP tools on Azure App Service, Azure AI Foundry with hybrid Azure AI Search retrieval, and separate Cosmos DB stores for ticket/audit data and conversation memory.

## Rationale

The proposal favors explicit workflow state, replaceable tool boundaries, policy-grounded retrieval, and separate access and retention boundaries. The options and rejection rationales were reported by the user as previously evaluated by the architecture group and were not independently verified.

## Affected Components

* Teams, Azure Bot Service, and Microsoft Entra ID OBO authentication
* App Service, LangGraph orchestration, and internal MCP tool execution
* Azure AI Foundry, moderation, Azure AI Search, and policy-document storage
* Ticket/audit persistence, conversation memory, HRIS/Graph connectors, and SLA events
